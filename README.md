# Sim Seiei

เกมแนว *The Sims 1* เขียนด้วยภาษา **C** ล้วนๆ จากศูนย์ (from scratch)
ใช้เทคนิคยุคเดียวกับ The Sims 1 คือ **Win32 API** (สร้างหน้าต่าง + รับอินพุต) และ **GDI** (วาดภาพ)

> โปรเจกต์เรียนรู้ทีละก้าว — แต่ละ commit คือ 1 step ย้อนดูได้ว่าแต่ละก้าวเพิ่มอะไรเข้าไป

## โครงสร้างโปรเจกต์
```
simseiei/
├── mockup/menu.html   แบบร่างหน้าเมนู (ออกแบบก่อนลงมือเขียน)
├── src/
│   ├── main.c         จุดเริ่มต้น (WinMain): เปิดหน้าต่าง + เข้าวงวนหลัก
│   ├── window.h/.c    ชั้น platform: จัดการหน้าต่าง Windows + วงวนหลัก
│   └── menu.h/.c      ชั้น scene:    หน้าเมนู (วาดหัวเรื่อง/ปุ่ม + รับคลิก)
├── Makefile
└── bin/               ไฟล์ที่ build แล้ว (ไม่เก็บเข้า git)
```

## แนวคิดสถาปัตยกรรม (architecture)
- **main.c** ทำหน้าที่แค่ "ต่อสาย" — สร้างหน้าต่างแล้วสั่งวิ่ง
- **window** (platform) รู้จักแต่เรื่องของ Windows — ไม่รู้ว่าจะวาดเมนูอะไร
- **menu** (scene) รู้ว่าจะวาดอะไรและตอบสนองคลิกยังไง — ไม่ยุ่งกับ Win32 โดยตรง
- เวลาคลิก menu จะคืน "action" กลับไปให้ window ตัดสินใจ (เช่น ปุ่ม Quick -> ปิดโปรแกรม)

> ตอนนี้ window เรียก menu ตรงๆ เพราะมีฉากเดียว พอมีหลายฉาก (เมนู/ในเกม) ค่อยเพิ่มระบบ scene ทีหลัง

## วิธี build & run (Windows + MinGW / MSYS2)
รันจากโฟลเดอร์ราก (root) ของโปรเจกต์:

```
make run
```

หรือคอมไพล์ตรงๆ ด้วย gcc:
```
gcc -g3 -O0 -Wall src/*.c -o bin/simseiei.exe -lgdi32
./bin/simseiei.exe
```

- `-lgdi32` = ลิงก์ไลบรารีวาดภาพ (GDI)
- `-mwindows` = (ใส่เพิ่มก็ได้) ไม่ให้มีหน้าต่าง console ดำๆ เด้งขึ้นมาด้วย

## Steps (ตามลำดับ commit)
- **mockup** — ออกแบบหน้าเมนูเป็นภาพก่อน (HTML/CSS)
- **โครงโปรเจกต์** — วาง folder structure + Makefile
- **step 1** — เปิดหน้าต่างเปล่าด้วย Win32
- **step 2** — พื้นหลังสีเขียวอ่อน
- **step 3** — หัวเรื่อง "Hello my game"
- **step 4** — ปุ่มเมนู 3 ปุ่ม (New Game / Load Game Save / Quick)
- **step 5** — คลิกปุ่ม Quick แล้วออกจากโปรแกรม (hit testing)
